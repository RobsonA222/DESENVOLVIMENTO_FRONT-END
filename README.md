##  Projetos desenvolvidos

Ao longo das aulas, desenvolvi projetos para colocar em prática os conteúdos estudados.

### 1. Meu Portfólio — Projeto Minha Identidade

Desenvolvimento de uma página pessoal para apresentar minha trajetória, conhecimentos, tecnologias e projetos.

**O que pratiquei:**

- Estruturação com HTML5.
- Estilização com CSS3.
- Organização de seções.
- Navegação por links internos.
- Apresentação pessoal e profissional.

**Tecnologias:** HTML5 e CSS3.

### 2. CodeWave Summit 2026 — Interface Express

Criação de uma landing page para um evento fictício voltado à tecnologia e programação, com o objetivo de apresentar conteúdos e incentivar iniciantes a conhecerem o universo do desenvolvimento.

**O que pratiquei:**

- Criação de layouts.
- Organização de menus de navegação.
- Estruturação de cards informativos.
- Estilização de botões e seções.
- Aplicação de conceitos de responsividade e acessibilidade.

**Tecnologias:** HTML5 e CSS3.

### 3. DevPath — Painel Interativo

Desenvolvimento de um painel interativo que apresenta orientações de aprendizagem de acordo com a tecnologia escolhida pelo usuário.

**O que pratiquei:**

- Integração entre HTML, CSS e JavaScript.
- Captura de informações de formulários.
- Utilização de funções e estruturas condicionais.
- Manipulação do DOM.
- Eventos de clique e envio de formulários.
- Alternância entre tema claro e escuro.

**Tecnologias:** HTML5, CSS3 e JavaScript.

### 4. RB-Tecnologia — Interface Responsiva com Bootstrap

Criação de uma página para apresentação de cursos na área de tecnologia, utilizando componentes e recursos do Bootstrap.

**O que pratiquei:**

- Utilização do framework Bootstrap.
- Organização de conteúdo em cards.
- Sistema de Grid responsivo.
- Classes de espaçamento e estilização.
- Criação de interfaces adaptáveis a diferentes telas.

**Tecnologias:** HTML5, Bootstrap 5 e CSS.
